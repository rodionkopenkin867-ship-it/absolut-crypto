# 🛡️ Абсолют (Absolut) — AES-256 Text & File Encryptor

**Client-side encryption tool. Everything happens locally in your browser. No servers, no logs, no registration.**

Бесплатный и полностью анонимный веб-инструмент для шифрования текста и файлов с использованием военного стандарта **AES-256-GCM**. Вся криптография выполняется локально на устройстве пользователя.

👉 **[Попробовать живую демонстрацию (Live Demo)](https://шифруем-всё.online/)**

## ✨ Основные возможности
- 🔒 **AES-256-GCM**: Один из самых надежных алгоритмов симметричного шифрования в мире.
- 🛡️ **100% Client-Side**: Данные не отправляются на сервер. Шифрование происходит прямо в вашем браузере.
- 🔑 **До 4 паролей**: Каскадное шифрование. Каждый новый пароль создает дополнительный слой защиты.
- 🧂 **PBKDF2 (1 000 000 итераций)**: Защита от брутфорса. Подбор пароля займет столетия даже на суперкомпьютерах.
- 🔥 **Кнопка «Сжечь всё»**: Мгновенно очищает поля ввода, пароли и результаты из памяти.
- 🌓 **Темная и светлая темы**: С сохранением выбора в `localStorage`.
- 📱 **Адаптивный дизайн**: Работает на ПК, планшетах и смартфонах.

## ⚙️ Технические детали
- Написан на чистом HTML, CSS и Vanilla JavaScript.
- Использует **Web Crypto API** для криптографических операций.
- Использует **Web Workers** для шифрования файлов, чтобы интерфейс не зависал при обработке больших объемов данных.
- Поддержка drag & drop для файлов.
- Хоткей `Ctrl+Enter` для быстрого запуска.

## 🔒 Приватность и Метрика
Проект создан для защиты ваших секретов. 
*Примечание:* В коде используется Яндекс.Метрика **исключительно для подсчета анонимных посещений**. Скрипт не имеет доступа к полям ввода, паролям или вашим файлам. Если вы хотите полностью анонимную версию — просто удалите блок `<script>` с Метрикой из `index.html`.
